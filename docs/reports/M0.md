## Migrations
```sql
-- V1__baseline.sql
-- M0 baseline: the two tables every tenant-ready install needs.
-- Every business table carries workspace_id from day one (CLAUDE.md domain rule 1).

create table workspace (
    id         uuid        primary key,
    name       text        not null,
    settings   jsonb       not null default '{}'::jsonb,
    created_at timestamptz not null default now()
);

create table app_user (
    id            uuid        primary key,
    workspace_id  uuid        not null references workspace (id),
    email         text        not null,
    password_hash text        not null,
    role          text        not null check (role in ('admin', 'member', 'viewer')),
    created_at    timestamptz not null default now(),
    constraint uq_app_user_workspace_email unique (workspace_id, email)
);

create index idx_app_user_workspace on app_user (workspace_id);
```

Applied after the initial M0 build, on the same branch.

**Local mode (D-012).** Removed GitHub Actions CI and the PR template; `docs/WORKFLOW.md` rewritten for local-only
development (local `./gradlew build` is the gate, human merges with `--no-ff`, GitHub is a backup). Review

**M0 review fixes.**
- **B1** Worker now runs non-web (`spring.main.web-application-type=none`) and publishes no port; `SecurityConfig`
  is guarded with `@ConditionalOnWebApplication(SERVLET)` so the non-web worker starts cleanly. A non-web app with
  no non-daemon thread exits right after startup, so `spring.main.keep-alive: true` keeps the worker alive until
  the M2 job loop provides its own long-running work.
- **B2** `V3__app_user_email_ci.sql` lowercases existing emails, drops `unique(workspace_id, email)` and adds a
  unique index on `lower(email)`. `AdminBootstrap` and `AppUserDetailsService` normalize email to lowercase, so
  login is case-insensitive. (V1/V2 untouched.)
- **B3** `SecurityConfig` documents why it is safe: STATELESS sessions, CSRF disabled only because no session
  cookie is issued, and no wildcard CORS.
- **B4** `AdminBootstrap` logs a warning when `app_user` is empty but the env vars are missing, and refuses
  passwords shorter than 12 characters.
- **B5** Postgres host port is configurable: `"${POSTGRES_HOST_PORT:-5432}:5432"` in compose, documented in
  `.env.example` and the README.
- **B6** `gradle.lockfile`s (core, app, settings) confirmed committed.
