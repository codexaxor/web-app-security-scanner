## What was built
- `docker-compose.prod.yml` — overlay over the base file: LAN-facing ui port (`0.0.0.0:80`) + `restart: unless-stopped`; api/postgres stay loopback-only. Used with `-f docker-compose.yml -f docker-compose.prod.yml`.
- `ui/nginx.conf` — the `/api/` proxy now resolves the `api` service at request time via Docker DNS (`resolver 127.0.0.11`, host through a variable), so an api-only restart no longer pins a stale IP (the login-breaks-on-restart bug).
- `.env.prod.example` — VM template: fresh AES/HMAC keys, DB password, bootstrap admin, HTTP-mode cookie flag, uid/gid 1001, docker-gid 988, `POSTGRES_HOST_PORT=15432`, `SECSCAN_INSTANCE_ID=vm`.
- `docs/DEPLOY_VM.md` — full runbook: prereqs, rsync+build deploy, secrets, scanner-image note, day-to-day, upgrade safety (sessions are in-memory; never `down -v`), backups (installed) + restore procedure.
- `docs/DECISIONS.md` — D-105 (deploy decision; resolves OD-34–37, settles OD-5/Docker-socket for the internal demo; VPN-only TLS waiver with an HTTPS + D-101 revisit).
- `CLAUDE.md`, `docs/SPEC.md` — prod-compose command; Hosting open-decision marked resolved.
