## Migrations
**None.** M8.8 adds no table or column. `app_user.email` is a plain lowercased-unique `text` column (V1/V3), so
the non-email demo username needs no schema change; sessions are in-memory; the CSRF token is in-session; the
Ignored reason filter is a new workspace-scoped repository query, not a new column.

## Decisions
- **D-091** demo mode (`SECSCAN_DEMO_MODE`; non-email login; WARN; off ⇒ no-`@` lockout; never on a shared host).
- **D-092** browser session (amends D-067(a)): server session cookie (HttpOnly+Secure+SameSite=Strict, id
  rotation, idle 30 m / absolute 8 h), CSRF = session **synchronizer** token in the auth JSON bodies +
  `X-CSRF-TOKEN` header (not a double-submit cookie — the D-067(e) `document.cookie` guard forbids that; CSP
  unchanged), stateless Basic kept and CSRF-exempt, `SECSCAN_SESSION_COOKIE_SECURE` (default true).
Both are recorded in `docs/DECISIONS.md`.

## API changes (additive, workspace-scoped, lists paginated)
- `POST /api/v1/auth/login` (JSON; 415 otherwise), `POST /api/v1/auth/logout` (JSON + CSRF), `GET /api/v1/auth/session` → `{username, demoMode, csrfToken}`.
- `GET /api/v1/ignored` gains an optional `reason` filter (server-side count stays exact).
- `GET /api/v1/repositories/{id}/branches` now returns `BranchPage` (adds `searchTruncated`); routed provider-neutrally through the adapter.
- `PUT /api/v1/gitlab/connections/{id}` (rotate) rejects a `credential_kind='none'` connection (400).
- `MissingCredentialException` → 409 `CONNECTION_TOKEN_MISSING`; the GitLab 404 message adds a full-path/paste-URL hint.

## Deviations from SPEC / brief
- **CSRF** is a session **synchronizer** token (JSON body + header), not a double-submit cookie — the D-067(e)
  guard forbids `document.cookie`; strictly stronger, CSP unchanged. (Pre-approved.)
- **GitHub branch search** (S5b, Should-fix): no server-side search on GitHub, so the adapter does an exact-match
  fast path, else fetches ≤10 pages of 100 (cap 1,000), filters in memory, caches repo+branch list per repo for
  5 min (LRU-bounded to 500 entries), and flags `truncated` past the cap.
- **AuthController** made `@ConditionalOnWebApplication(SERVLET)` — a latent S3 bug (it needs the web-only
  `AuthenticationManager`, so it must not load in the non-web worker context). Earlier full builds had the worker
  ITs cached; `./gradlew build --rerun-tasks` is now green.
- **Deferred e2e** (Known gaps): demo-mode ribbon and live-status completion.
