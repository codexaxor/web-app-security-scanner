# M8.11 — UI redesign + navigation

Branch `feature/m8.11-ui-redesign` (worktree `~/Projects/secscan-ui`), `ui/` only. Ran in parallel with
M8.10; **M8.11 merges first.** No `app/`/`core/`/migration/compose/nginx changes, no new runtime deps.
Full slice-by-slice log and commit hashes: `docs/reports/M8.11-worklog.md`.

## What shipped (scope items 1–8)

1. **Design tokens** — one `:root` system in `ui/src/styles/tokens.css`: added the brand/shell group
   (`--brand-navy #0B1530`, `--shell-*`), motion (`--transition`, `--transition-fast`) and layering
   (`--z-drawer/-palette/-toast`) tokens; added `--sp-5`; removed the last one-off hex fallbacks and fixed two
   undeclared refs. `contrast.test.ts` extended with the shell pairs.
2. **Theme (D-099)** — LIGHT by default, DARK via the user-menu toggle, **no "system"**; remembered across
   reloads via `ui/src/lib/themeStore.ts` (localStorage, single `secscan-theme` key, `try/catch` → light). The
   security guard now permits `localStorage` only in that one file and asserts its key/values/members, with a
   self-test. WCAG AA in both themes (`contrast.test.ts` + e2e).
3. **App shell** — deep-navy sidebar (brand chrome, constant across themes) grouped into Overview / Findings /
   Sources & repos / Workspace with collapsible sections and a clear active state; a user menu (theme toggle +
   Sign out); breadcrumbs on detail routes (`/repositories/:id`, `/feed/:groupId`, `/select`); a ⌘K/Ctrl+K
   quick-jump palette (pages + repositories via the endpoint's server-side search). Original inline-SVG
   `BrandMark`.
4. **Interactivity** — whole-row **real link** (stretched `::after`; Enter is e2e-tested; middle-click / Ctrl-click are native `<a href>` behaviour of that real link — not separately tested;
   no onClick-only `<tr>`) on Repositories and Feed, with row buttons/menus kept clickable above the overlay;
   sticky table headers; hover/focus-visible; skeleton loaders everywhere (`TableSkeleton` on lists,
   `SkeletonLines` in the panel/wizards/drawer); all transitions ≤200 ms, disabled under
   `prefers-reduced-motion`.
5. **Friendliness** — next-action CTAs on every list empty state (Dashboard, Feed, Repositories, Ignored,
   Sources, repo Issues/Scans tabs); a Dashboard first-run checklist (add source → add repository → run first
   scan) derived from existing list counts that auto-hides when all three are done (no dismiss button, per
   approved change #6).
6. **Restyle** — login card (with reserved room for a future "Create account" link; no route — M8.10 owns
   sign-up), plus the shared-class polish (page-header separation, card hover) that refreshes every page.
   Behaviour unchanged (existing per-page e2e specs still green).
7. **Responsive** — 1440 / 1280 / 390; the sidebar collapses to an off-canvas drawer below ~1024; wide tables
   scroll inside their card (no horizontal page scroll at 390); the checklist/palette adapt at phone width.
8. **Guard + e2e** — the guard still fails on any `Authorization: Basic` construction; e2e selectors updated for
   the new shell/theme without weakening assertions.

## Decisions

  which also closes the M10 register item "Theme (light/dark) preference persistence".

## Serial-vitest change (recorded here per request)

`ui/vite.config.ts` now sets `test.fileParallelism: false`. Under vitest's default file-parallelism the M8.8
`BranchPicker.test.tsx` (`findByRole`, real timers) timed out when many jsdom environments ran concurrently —
the M8.11 test additions tipped the load over. The suite passed in isolation and single-threaded (149/149).
Serial execution is deterministic (~15 s), touches no test and weakens no assertion. Approved by Sajal mid-run.
