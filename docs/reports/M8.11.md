## What shipped (scope items 1–8, S0–S10)

1. **Design tokens** — one `:root` system in `ui/src/styles/tokens.css`: brand/shell group (`--brand-navy
   #0B1530`, `--shell-*`), motion (`--transition`, `--transition-fast`), layering (`--z-drawer/-palette/-toast`),
   `--sp-5`, `--appbar-h` (R6); the last one-off hex fallbacks removed and two undeclared refs fixed.
2. **Theme (D-099)** — LIGHT by default, DARK via the user-menu toggle, **no "system"**, and no
   `@media (prefers-color-scheme)` token block (R6/N-4): dark exists only under `[data-theme="dark"]`, so first
   paint is light and the OS setting is never followed. Remembered across reloads via `ui/src/lib/themeStore.ts`
   (localStorage, single `secscan-theme` key, values `light|dark`, every access `try/catch` → light). The guard
   permits `localStorage` only in that file and asserts its key/values/members, with a self-test.
3. **App shell** — deep-navy sidebar (constant across themes) with section labels Overview / Findings /
   Sources & repos / Workspace (always expanded — S11.5 replaced per-group chevrons with one collapse-to-icons
   control in the footer); clear active state; user menu (theme toggle + Sign out); a top bar on every page
   (breadcrumbs on `/repositories/:id`, `/feed/:groupId`, `/select`; the page name elsewhere) with a search
   field that opens the ⌘K/Ctrl+K quick-jump palette (pages + repositories via the server-side search, one page
   of 6, debounced 150 ms). Original inline-SVG `BrandMark`.
4. **Interactivity** — whole-row **real link** on Repositories and Feed (stretched `::after`; Enter is
   e2e-tested; middle-click / Ctrl-click are the native behaviour of that real `<a href>` — **not separately
   tested**); no onClick-only `<tr>` remains — the repository Issues row opens its panel through a real
   `<button>` (S11.9, Enter + Space e2e). Row buttons/menus and the repository path (selectable, R6/N-8) sit
   above the overlay. Sticky table headers (below the app-bar at 721–1024 px, R6/N-3); hover/focus-visible;
   skeleton loaders (`TableSkeleton` on lists, `SkeletonLines` in panels/wizards/drawer); transitions ≤200 ms,
   disabled under `prefers-reduced-motion`.
5. **Friendliness** — next-action CTAs on every list empty state (Dashboard, Feed, Repositories, Ignored,
   Sources, repo Issues/Scans tabs, and `/select` — "Add a source first", R2); a Dashboard first-run checklist
   (add source → add repository → run first scan) from existing list counts, auto-hidden when all three are done
   (no dismiss button, approved change #6), refreshed immediately by source/select/scan mutations (R6/N-1).
6. **Restyle** — login card (reserved room for a future "Create account" link; no route — M8.10 owns sign-up);
   shared page-header separation and card polish.
7. **Responsive** — 1440 / 1280 / 900 / 390; the sidebar becomes an off-canvas drawer below ~1024 px; wide tables
   scroll inside their card (no horizontal page scroll at 390); checklist/palette/top-bar search adapt at phone
   width.
8. **Guard + e2e** — the guard still fails on any `Authorization: Basic` construction; e2e selectors updated for
   the new shell/theme without weakening assertions (the one coverage loss — feed last page — restored in R5).

## Serial vitest

`ui/vite.config.ts` sets `test.fileParallelism: false`. Under vitest's default file-parallelism the M8.8
`BranchPicker.test.tsx` (`findByRole`, real timers) timed out when many jsdom environments ran concurrently.
Serial execution touches no test and weakens no assertion (approved by Sajal mid-run). Observed once in R2: one
unidentified test failed in a single serial full-suite run and passed in the next 11 full runs, so a residual
load/timing flake remains in the suite. The R1/R2 files were stress-run 15× in isolation, all green.

## Deferred

- **`/projects` decrypt failure → 409 (M8.10)** — `GET /api/v1/gitlab/connections/{id}/projects` answers a
  generic 500 `INTERNAL "Unexpected error."` when the stored token cannot be decrypted (e.g. the e2e seed's fake
  ciphertext, or a rotated encryption key). It should be a typed 409 with an actionable message ("re-enter the
  token for this source"). Backend change, out of this UI-only milestone; the UI already scopes the error (R2).
- **UI reformation round 2 (post-release)** — a second UI design pass after release; scope to be defined by the
  human (not specified in this milestone).
- **Residual vitest timing flake** (one unidentified failure in ~12 serial runs; see "Serial vitest").
