## Migrations
```sql
-- V19__scan_branch.sql  (M8.1; FROZEN — applied to the dev DB 2026-10-25 ~19:10. Any schema fix is V20, D-077.)
alter table repository add column scan_branch    text;
alter table repository add column branch_missing boolean not null default false;
alter table scan        add column branch         text;

-- Backfill existing scans from the repository's known default branch so historical rows carry a branch.
update scan s
   set branch = r.default_branch
  from repository r
 where s.repository_id = r.id
   and s.branch is null
   and r.default_branch is not null;
```

## Deviations from the approved plan
- **V19 also adds `repository.branch_missing`** (boolean) — approved after the fact; folded into V19 before V19 ran on any persistent DB. Drives the "branch missing — choose another" UI flag (A5).

- `POST /api/v1/repositories` response shape changed (`RepositoryView[]` → `SelectResult`) for B1; the UI and three ITs were updated.
