## Approved plan changes (2026-11-05)

1. **Decision number:** M8.10 owns D-093…D-098 (its D-095 = light default + dark toggle). Our guard
   amendment is **D-099** "Theme persistence: narrow localStorage allowlist (amends D-067e)",
   append-only to `docs/DECISIONS.md`; it also closes the M10 register item *"Theme (light/dark)
   preference persistence"*. No edits to `CLAUDE.md` or `SPEC.md`; any needed doc changes are listed
   in the M8.11 report instead.
2. **Do not touch** the nginx config under `ui/` — M8.10 owns it.
3. **Guard:** `localStorage` allowed only in `src/lib/themeStore.ts`, and the guard additionally
   asserts that file uses only the key `"secscan-theme"` with values `light|dark`. A guard self-test
   proves the guard FAILS if another key, another value, or `localStorage` in another file appears.
4. **Whole-row click:** every clickable row contains a real `<a>` link (Enter, middle-click,
   Ctrl/⌘-click all work); the row click only extends the link's hit area. No `onClick`-only `<tr>`.
   Keyboard activation is asserted in the repositories e2e spec.
5. **⌘K palette:** use the repositories endpoint's server-side `search` (it has one); never fetch all
   pages. `role="dialog"`, focus trap, Esc closes, Up/Down move the selection, Enter navigates. All
   covered in `CommandPalette.test.tsx`.
6. **First-run checklist:** no dismiss button (would need storage); auto-hides once all three steps
   are done.
7. **Brand:** text "SecScan" + a simple original inline-SVG mark. Nothing resembling SecureLayer7 /
   BugDazz logos, wording or images.
8. **Login:** leave room under the form for a future "Create account" link, but add no sign-up
   placeholder and no route (M8.10 owns sign-up).

## Decisions settled at plan time

- **D-099** (localStorage persistence): `src/lib/themeStore.ts` is the only file the guard exempts;
  single key `secscan-theme` ∈ {`light`,`dark`}; every access wrapped in try/catch and falls back to
  light; credentials / CSRF tokens / secrets are never stored. Amends D-067(e).
- **Navy shell, both themes:** sidebar + top bar are deep navy `#0B1530` in light AND dark (brand
  chrome); the content area flips light/dark. New `--shell-*` token group with its own AA-verified
  text pairs, checked in `contrast.test.ts`.
