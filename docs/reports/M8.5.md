## Migrations
```sql
-- V20__iac_severity_override.sql
create table iac_severity_override (
    check_id   text        primary key,
    severity   text        not null check (severity in ('CRITICAL', 'HIGH', 'MEDIUM', 'LOW')),
    note       text,
    created_at timestamptz not null default now()
);

-- V21__level2_taxonomy.sql
alter table issue_group add column level2_category text;
alter table issue_group add column owasp_category  text;
create index idx_issue_group_level2 on issue_group (workspace_id, level2_category);
```
Both additive (V1–V19 frozen). Apply to an empty DB (every Testcontainers IT applies V1→V21) and to existing data
(`TaxonomyBackfillIT` seeds pre-V21 groups → backfill → null count 0; `IacSeverityOverrideIT` on seeded rows).
